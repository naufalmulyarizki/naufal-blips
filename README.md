# Naufal Create Blip System RedM

Script membuat blip pada redm server

# Features 
- Configurasi mudah untuk membuat blip
- Script ketika di restart blip terhapus dan terbuat lagi

# Installation
- Download Resource
- Masukkan ke dalam resource kamu
- refresh dan start script
